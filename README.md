# Солод Руси — сайт

Статический сайт (HTML/CSS/JS, без сборки). Достаточно залить папку на любой хостинг/CDN.

```
index.html      главная
privacy.html    политика конфиденциальности
css/style.css   стили
js/main.js      маска телефона, валидация, анимации
assets/         логотип и фавиконка (SVG)
assets/img/     фотографии (JPG, по две версии: полная и мобильная)
_source-images/ исходные PNG из генератора — в продакшен не заливать
```

## Что нужно доделать клиенту (одна вещь)

Поднять эндпоинт `POST /api/submit`, принимающий JSON `{name, email, phone, company, region, product, volume, page}`
и возвращающий HTTP 200 (письмо менеджеру / CRM). Пока эндпоинта нет, форма честно показывает ошибку
и предлагает отправить письмо, Telegram или позвонить — «успешно отправлено» не рисуется никогда.

Адрес меняется в одном месте: атрибут `action` у `<form id="orderForm">` в `index.html`.

## Картинки

В `assets/img/` лежат сжатые JPG. Для каждой — мобильная версия, подключена через `<picture><source media>`.
Все фотографии сгенерированы нейросетью: это не съёмка производства в Венёве. Подписи под ними
сформулированы нейтрально и ничего не утверждают про конкретный цех — при замене на реальные фото
подписи можно усилить.

`og:image` указан относительным путём. На боевом домене поменять на абсолютный
(`https://solodrusi.ru/assets/img/og-cover.jpg`) — иначе превью в мессенджерах не подтянется.

Промпты, которыми сгенерированы картинки, — в `PROMPTS-IMAGES.md`.

## Прочее
- Шрифты подключены с Google Fonts (`Unbounded` + `Manrope`, кириллица). Для самохостинга — скачать .woff2 и заменить `<link>` на `@font-face`.
- `og:image` не создан — при желании добавить картинку 1200×630 и мета-тег.
- Анимации отключаются при `prefers-reduced-motion: reduce`.
